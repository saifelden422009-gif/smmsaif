# smmsaif — النسخة المعاد بناؤها

## الروابط بعد التشغيل
- لوحة العميل: `http://localhost:3000/`
- لوحة الأدمن المنفصلة: `http://localhost:3000/admin`

## التشغيل
1. ثبّت Node.js على جهازك أو استخدم استضافة تدعم Node.js.
2. فك الضغط عن الحزمة.
3. شغّل `npm install`
4. عيّن متغيرات البيئة قبل النشر:
   - `ADMIN_PASSWORD` كلمة مرور قوية للأدمن (إلزامي تغيير الافتراضية)
   - `SESSION_SECRET` قيمة عشوائية طويلة وسرية
   - `NODE_ENV=production` في الاستضافة مع HTTPS
5. شغّل `npm start`.

## اختبار سريع
- سجّل دخول الأدمن من `/admin` بكلمة المرور المحددة في `ADMIN_PASSWORD`.
- اضغط «إنشاء عميل جديد»، وانسخ رقم العميل.
- افتح `/` في تبويب آخر، وسجّل الدخول برقم العميل.
- أنشئ طلبًا، ثم ارجع إلى `/admin` وغيّر حالته. رفض الطلب يرد المبلغ مرة واحدة.
- جرّب طلب شحن ثم وافق عليه من لوحة الأدمن.

## ملاحظات
- هذه حزمة تطبيق أولية قابلة للتشغيل، وليست استضافة منشورة بالفعل.
- قاعدة البيانات JSON مناسبة للتجربة الصغيرة فقط؛ استخدم قاعدة بيانات دائمة ومدارة في الإنتاج.
- أسعار سناب شات وبعض وحدات التسعير غير المحددة بالكامل وضعت كقيم مبدئية قابلة للتعديل.
- لا توجد بوابة دفع فعلية ولا تكامل API لتنفيذ خدمات المنصات؛ طلبات الشحن يراجعها الأدمن يدويًا.
- حماية إضافية مطلوبة قبل الاستخدام التجاري (قاعدة بيانات دائمة، حدود طلبات، نسخ احتياطي، CSRF وسياسة خصوصية).
